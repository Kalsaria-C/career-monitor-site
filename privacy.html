Privacy Policy

Effective September 30, 2026

Career Monitor is a personal desktop application maintained by Chintan Kalsaria. This policy describes the application and this informational website.

Information used by the application

The monitor uses the owner's configured recipient email address, selected companies, career preferences, and public job postings. It stores job identifiers, descriptions, matching results, notification history, generated email previews, and operational status on the owner's computer.

The application receives Google OAuth authorization tokens after the owner signs in and approves access. Tokens are stored in macOS Keychain. Google handles the sign-in process; the application does not request or store the owner's Google password.

Gmail permission and purpose

The application requests the https://www.googleapis.com/auth/gmail.send scope to send job-alert digests and setup-test emails to the configured recipient. It does not request Gmail inbox-reading, searching, or deletion scopes. It records Gmail's returned message identifier and delivery status to help prevent duplicate alerts and diagnose sending failures.

Career Monitor's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data sharing and service providers

Google receives the authorized email requests, recipient address, and outgoing message contents to deliver email. Messages remain subject to the Gmail account's settings and Google's policies. Public career-page providers receive normal network requests when the monitor retrieves their listings.

The monitor does not sell personal information, use Google user data for advertising, or use it to train general-purpose AI models. It does not upload the owner's resume to job sites or submit applications. The Python matching process runs locally and does not call an external language model.

If the owner manages or schedules the application through Codex, prompts, tool outputs, and information shared in that environment are handled under the owner's Codex/OpenAI settings and applicable policies. Google authorization tokens are not intentionally included in those outputs.

This website

This is a static site hosted on GitHub Pages. It has no sign-in form, analytics scripts, advertising, or application-controlled tracking cookies. GitHub may process technical visitor information, including IP addresses, when serving the site, under the GitHub Privacy Statement.

Retention and deletion

Local job history, email previews, and operational records remain until the owner deletes them. OAuth tokens remain in macOS Keychain until removed or invalidated. To stop access, disable the monitor's schedule and remove Career Monitor from Google Account connections. Remove the application's Keychain entry and local data/output files to delete its locally stored information.

Deleting local records does not delete already-sent emails. Those messages can be managed directly in Gmail. Information shared in Codex or a public GitHub issue must be managed through the respective service.

Security

The application uses HTTPS for Google authorization and Gmail API requests and stores OAuth tokens in macOS Keychain. Local preferences, job history, and previews rely on the owner's computer and account protections. No security measure guarantees absolute protection.

Changes and contact

This page will be updated when the application's data practices materially change. The effective date appears above. For support or privacy questions, use the project's GitHub issues. Public issues should never contain passwords, OAuth tokens, or private account data.
