# Career Monitor website

Static informational website for the personal Career Monitor desktop application.

- `index.html`: application purpose and Gmail permission explanation
- `privacy.html`: data handling, retention, deletion, and Google Limited Use statement
- `terms.html`: application purpose and limitations
- `styles.css`: shared responsive styling

Deploy with GitHub Pages from the root of the `main` branch. Only public website files belong in this repository. The application, resume, account configuration, tokens, and local job history are maintained separately.
